# 차곡 공개 시연

하루에 한 번, 식사와 활동을 묻고 답한 내용을 본인이 확인·수정해 남기는 생활기록 시제품 **차곡**의 공개 시연판입니다.

시연 주소: https://kangho-park.github.io/chagok-demo/

## 이 시연에서 되는 것

- 질문을 한 번에 하나씩 보여 주고, 답을 글자로 입력
- 저장 전에 내용을 확인하고 고치기 (양·시간·부정 표현 강조)
- 기억나지 않음 / 건너뜀 구분
- 날짜별 생활기록 노트, JSON 내보내기, 인쇄

## 알아둘 점

- 가상 내용만 입력하세요. 실제 병력·이름·개인정보는 입력하지 마세요.
- 기록은 브라우저 메모리에만 있고 새로고침하면 사라집니다. 서버로 전송하지 않습니다.
- 음성으로 답하는 기능은 개발 PC에 연결한 시연에서만 동작하며, 이 공개판에서는 가려 두었습니다.
- 진단·치료·인지 점수 기능이 아닙니다. 질문은 전문가 검토 전 단계입니다.

## 저장소 구성

이 저장소에는 빌드 결과물만 있습니다. `tools/make-public-demo.mjs`는 빌드된 `index.html`에 공개 시연 안내와 음성 조작부 숨김을 덧붙이는 후처리 스크립트입니다.
